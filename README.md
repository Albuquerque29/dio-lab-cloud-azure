# ☁️ Computação em Nuvem: Resumo Detalhado + Implementação com Azure

## 🧠 O que é Computação em Nuvem?

Computação em nuvem é um modelo de entrega de recursos de TI (servidores, armazenamento, redes, software etc.) por meio da internet. O usuário acessa sob demanda, pagando apenas pelo uso, sem a necessidade de infraestrutura local.

---

## 📦 Modelos de Serviço

### IaaS - *Infraestrutura como Serviço*
Fornece recursos básicos como máquinas virtuais, redes e armazenamento.  
**Exemplo**: Azure Virtual Machines.

### PaaS - *Plataforma como Serviço*
Ambiente completo para desenvolvimento e implantação de aplicações.  
**Exemplo**: Azure App Services.

### SaaS - *Software como Serviço*
Aplicações acessadas via navegador, sem instalação local.  
**Exemplo**: Microsoft 365.

---

## ☁️ Modelos de Implantação

- **Nuvem Pública**: Infraestrutura compartilhada, fornecida por provedores como Azure, AWS e Google Cloud.
- **Nuvem Privada**: Infraestrutura exclusiva de uma organização.
- **Nuvem Híbrida**: Combinação de nuvens públicas e privadas.

---

## ✅ Vantagens da Computação em Nuvem

- Escalabilidade sob demanda
- Redução de custos operacionais
- Acesso remoto global
- Backup e recuperação facilitados
- Alta disponibilidade e desempenho
- Segurança e conformidade com normas

---

## 🚀 Microsoft Azure: Plataforma de Nuvem da Microsoft

### 🔹 O que é o Azure?

Azure é a plataforma em nuvem da Microsoft, com mais de 200 serviços disponíveis: máquinas virtuais, banco de dados, DevOps, inteligência artificial, redes, entre outros.

---

### 🔹 Principais Serviços do Azure

- **Azure Virtual Machines (IaaS)**: Computação em nuvem com VMs.
- **Azure App Service (PaaS)**: Hospedagem de aplicações web.
- **Azure SQL Database**: Banco de dados relacional gerenciado.
- **Azure Storage**: Armazenamento de objetos, arquivos e filas.
- **Azure Active Directory**: Gerenciamento de identidade.
- **Azure Functions**: Execução de código sem servidor (serverless).

---

### 🔹 Exemplo de Implementação: Hospedar uma App Web com Azure App Service

1. Criar uma conta no [portal do Azure](https://portal.azure.com)
2. Criar um **Resource Group** (grupo de recursos)
3. Criar um **App Service Plan** (define localização e escalabilidade)
4. Criar um **App Service** (ambiente de hospedagem)
5. Fazer **deploy** do app via GitHub, FTP, Visual Studio ou CLI

---

### 🔹 Ferramentas de Gerenciamento no Azure

- **Azure Portal**: Interface gráfica via navegador
- **Azure CLI**: Gerenciamento via linha de comando
- **Azure PowerShell**: Automação com scripts
- **Azure Resource Manager (ARM)**: Infraestrutura como código (IaC)

---

### 🔹 Segurança e Compliance

- Conformidade com ISO, GDPR, LGPD, HIPAA, entre outros
- Controle de identidade com Azure Active Directory
- Criptografia de dados em trânsito e em repouso
- Firewall, controle de acesso e monitoramento com Microsoft Defender for Cloud
